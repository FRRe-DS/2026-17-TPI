Lee specs/ (spec.md, plan.md, tasks.md, guia.md), EN-CURSO.local.md si existe, la rama actual (git branch --show-current) y, si hay gh, los PR abiertos (gh pr list).

Responde en pocas líneas:
1. Por spec: estado, fase (spec, plan, tareas, PR de spec, implementación, validación, PR de implementación) y tareas hechas (x de y).
2. El siguiente paso exacto, con la skill que hay que usar.

No modifiques ningún archivo.
