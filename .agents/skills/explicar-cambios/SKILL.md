---
name: explicar-cambios
description: Úsala cuando pregunte qué cambió desde un commit, una fecha o la última vez que revisé el proyecto, o qué hizo cada integrante.
---
1. git fetch y git log --stat desde el punto indicado (si no lo indico, pregúntame), con autor.
2. Agrupa los commits por spec y tarea según su prefijo (NNN/Tn, NNN/V, NNN:) y, dentro de cada grupo, por autor.
3. Por grupo: qué cambió y por qué, apoyándote en la spec y la guía correspondientes.
4. Señala lo que cambió sin spec, issue ni guía: es lo primero que conviene revisar.
